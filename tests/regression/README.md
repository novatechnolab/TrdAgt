# TradeSignal Regression Suite

## Overview

Three-layer regression suite to ensure zero behavioural change during backend migration.

```
Layer 1 (Browser)  → Golden capture + visual regression runner
Layer 2 (API E2E)  → HTTP-level pytest against running backend
Layer 3 (Unit)     → Indicator math parity (Python vs JS)
```

---

## Files

```
tests/regression/
├── fixtures/
│   └── ohlcv_factory.js       # 12 deterministic OHLCV scenarios
├── golden/
│   └── golden.json            # ← Generated by Step 1 below (commit this)
├── golden_capture.html        # Step 1: Capture JS golden outputs
├── regression_runner.html     # Step 3: Visual diff post-migration
└── api_e2e_test.py            # Step 2/4: API-level pytest

app/backend/tests/
├── conftest.py                # Shared fixtures
└── test_indicator_parity.py   # Step 2/4: Indicator unit tests
```

## Step-by-Step Usage

### STEP 1 — Capture Golden Outputs (run BEFORE any migration)

1. Start the backend: `cd app/backend && python server.py`
2. Open in browser: `tests/regression/golden_capture.html`
3. Click **▶ RUN ALL SCENARIOS**
4. Click **⬇ DOWNLOAD golden.json**
5. Save to: `tests/regression/golden/golden.json`
6. **Commit this file** — it is the regression baseline

---

### STEP 2 — Run API E2E Tests (pre-migration baseline)

```bash
pip install pytest requests

# Backend must be running
pytest tests/regression/api_e2e_test.py -v -k "not TestGoldenComparison"
```

Expected: All `TestConnectivity` and `TestResponseSchema` tests pass.
`TestGoldenComparison` is skipped until golden.json exists.

---

### STEP 3 — Run Indicator Parity Tests (pre-migration)

```bash
pytest app/backend/tests/test_indicator_parity.py -v
```

Expected: All tests `xfail` — `indicators.py` does not exist yet.
This establishes the pre-migration baseline.

---

### STEP 4 — Post-Migration Verification

After completing all migration phases:

**4a. Indicator parity (must all PASS now):**
```bash
pytest app/backend/tests/test_indicator_parity.py -v
# Target: 0 failures, 0 xfail
```

**4b. API schema (must all PASS):**
```bash
pytest tests/regression/api_e2e_test.py -v -k "not TestGoldenComparison"
```

**4c. Golden comparison (exact behaviour check):**
```bash
pytest tests/regression/api_e2e_test.py -v -k "TestGoldenComparison"
# All 12 scenarios × 3 test types = 36 tests
# Target: 0 FAIL (WARN = within tolerance = acceptable)
```

**4d. Browser visual regression:**
1. Open `tests/regression/regression_runner.html`
2. Load `golden/golden.json`
3. Click **▶ RUN REGRESSION**
4. Target: All 12 cards green (PASS) or orange (DRIFT within tolerance)
